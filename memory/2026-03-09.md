## 今日任务：查看火山引擎 Coding Plan 额度

### 任务背景
- 用户询问如何查看火山 Coding Plan 的额度
- 之前可能在费用中心的资源包中查找，但实际上 Coding Plan 是在火山方舟控制台管理

### 查看流程

1. **登录火山引擎控制台**
   - 访问 https://console.volcengine.com/

2. **进入火山方舟**
   - 路径：产品与服务 → 人工智能与算法 → 火山方舟
   - 或直接访问：https://console.volcengine.com/ark/region:ark+cn-beijing/overview

3. **找到开通管理页面**
   - 左侧菜单：系统管理 → 开通管理
   - 点击「Coding Plan」标签页

4. **查看额度详情**
   - 套餐名称：Coding Plan Lite / Pro
   - 套餐用量：显示已使用百分比
   - 剩余天数：当前周期剩余天数
   - 下次刷新时间

4. Lite 和 Pro 的区别主要在于额度大小和适用场景
